# План минутного скринкаста после завершения проекта

Не записывать демонстрацию до реализации и проверки оставшихся частей.

0–10 секунд: показать запущенные сервисы (`docker compose ps`) и успешное завершение генератора.
10–25 секунд: открыть дашборд и показать панели трёх ручек с данными под нагрузкой.
25–40 секунд: показать p50/p95/p99, RPS и минимум два кода ошибок.
40–55 секунд: переключить датацентр и под, затем All; показать изменение данных.
55–60 секунд: показать ссылку на публичный репозиторий и команду запуска в README.

До записи: дождаться данных, выбрать читаемый масштаб, увеличить шрифт терминала,
закрыть .env и личные вкладки. Не тратить время на вступление.

Поля для PR:
- заголовок: [devops] или [fullstack], работа 1, ФИО;
- студент: Дарья Созинова (проверить требуемое написание);
- группа: заполнить;
- репозиторий: заполнить;
- скринкаст: заполнить.

Точное место изменения в репозитории курса проверить по его текущему README перед отправкой PR.
