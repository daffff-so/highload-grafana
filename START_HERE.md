# Первый запуск за компьютером

1. Распакуй архив и открой папку, где находится pom.xml, в IntelliJ IDEA.
2. Убедись, что Docker запущен: `docker info`.
3. В терминале этой папки: `cp .env.example .env`.
4. Запусти `docker compose up --build`. Терминал оставь открытым.
5. В другом терминале проверь: `docker compose ps`.
6. Открой http://localhost:8081/health и http://localhost:8082/health.
7. Если есть Python 3: `python3 scripts/smoke_test.py`.
8. Открой Grafana http://localhost:3000, логин и пароль возьми из .env.

На этом этапе Grafana пустая, а targets Prometheus DOWN из-за отсутствия /metrics.
Это ожидаемое состояние заготовки, а не выполненная домашняя работа.

Если приложение не стартует, сохрани вывод:
`docker compose logs --tail=100 app-1 app-2`.
Если проблема при сборке — пришли первые строки ERROR и последние 30 строк вывода.
Не присылай .env с настоящими паролями.

после этого реализуем выбранное тобой решение. Переписывать CRUD не нужно.
